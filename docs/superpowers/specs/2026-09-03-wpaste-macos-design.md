# WPaste macOS 剪贴板应用设计

## 1. 产品目标

WPaste 是一款面向 macOS 15 及更高版本的原生剪贴板历史工具。应用常驻菜单栏，通过全局快捷键在当前鼠标所在屏幕底部呼出横向悬浮面板，让用户搜索、选择并快速粘贴最近复制的内容。

首版作为官网下载安装的独立应用交付，使用本地存储，不包含账号、iCloud 同步、智能/AI、订阅、购买或遥测功能。

## 2. 首版范围

### 2.1 支持的内容

- 纯文本
- URL 链接及链接预览
- 图片
- 单文件与多文件列表

首版不支持富文本样式、颜色数据、音视频内容预览、OCR、AI 摘要或智能分类。

### 2.2 核心能力

- 后台监听系统剪贴板并记录历史。
- 相同内容再次复制时更新最近使用时间并移至首位，不产生重复记录。
- 搜索文本内容、URL、文件名和来源应用。
- 用户可创建、重命名、排序和删除 Pinboard。
- 一条历史记录可收藏到多个 Pinboard；删除 Pinboard 不删除原历史记录。
- 默认自动粘贴到呼出面板前正在使用的应用；设置中可改为只写回系统剪贴板。
- 支持纯文本粘贴、键盘导航和数字快速粘贴。

## 3. 平台与交付

- 最低系统版本：macOS 15 Sequoia。
- 开发语言：Swift 6。
- UI：SwiftUI 为主，AppKit 负责系统级窗口和输入集成。
- 主要运行架构：Apple Silicon。
- 分发方式：官网下载安装的独立 `.app`。
- 正式发布流程预留 Developer ID 签名、Apple 公证和 DMG 打包配置。
- 应用常驻菜单栏，默认不显示 Dock 图标；菜单栏菜单提供打开设置、暂停记录和退出应用。

## 4. 系统架构

### 4.1 ClipboardMonitor

轮询 `NSPasteboard.general.changeCount` 检测剪贴板变化，按优先级解析文件列表、图片、URL 和文本。采集后生成稳定内容指纹，先交给隐私过滤器，再交给历史存储。应用自己执行回写或粘贴时设置短期抑制标记，避免形成重复采集循环。

### 4.2 PrivacyFilter

在任何持久化操作之前执行过滤：

- 忽略用户配置的来源应用。
- 忽略已知密码管理器来源。
- 忽略带瞬时、保密或禁止历史记录语义的剪贴板类型。
- 暂停记录开启时拒绝所有新记录。

过滤决定不会把被拒绝内容或其预览写入磁盘。

### 4.3 HistoryStore

使用 Core Data 的 SQLite 持久化存储记录元数据、文本、设置和 Pinboard 关系。图片原图与缩略图存放在应用的 Application Support 目录，数据库只保存相对路径和元数据。

文件记录不复制源文件，只保存文件路径、文件名以及在可用情况下创建的安全作用域书签。再次粘贴时校验文件是否仍存在；失效记录继续显示，但标记为“文件已不存在”并禁止粘贴。

### 4.4 PasteCoordinator

呼出面板前记录前台应用。用户确认后，把目标内容写入系统剪贴板，关闭面板并恢复目标应用焦点，再通过辅助功能 API 发送粘贴按键。若缺少辅助功能权限、目标应用已经退出或按键模拟失败，内容仍保留在系统剪贴板，并显示非阻塞提示。

纯文本模式只写入字符串表示。

### 4.5 ShortcutManager

注册并持久化以下全局或面板内快捷键：

- 呼出/关闭剪贴板历史。
- 前后移动选中项。
- `Return` 确认粘贴，`Escape` 关闭。
- `Command + 1...9` 快速粘贴可见位置。
- 临时切换纯文本粘贴模式。

用户可修改快捷键。保存前检测应用内重复；系统级注册失败或冲突时，保留旧快捷键并明确提示。设置页支持恢复默认值。

### 4.6 OverlayWindowController

使用 AppKit 管理无边框、透明背景的非标准悬浮窗口，并在 SwiftUI 中渲染内容。窗口显示于鼠标所在显示器底部的安全区域，宽度适配当前屏幕。面板支持键盘焦点、横向滚动，并在失去焦点或用户按下 `Escape` 后关闭。

### 4.7 SwiftUI 界面

SwiftUI 负责历史卡片、搜索栏、Pinboard 导航、菜单栏内容和设置窗口。状态通过明确的 Store/ViewModel 暴露，不让视图直接访问剪贴板或数据库。

## 5. 主面板设计

### 5.1 导航区域

顶部包含搜索、剪贴板历史、用户自定义 Pinboard 和新建 Pinboard 按钮。历史视图按最近使用时间倒序显示；切换 Pinboard 后仅展示属于该收藏板的内容。

### 5.2 卡片

- 文本：显示来源应用、相对时间、文本摘要和字符数。
- 链接：显示域名、标题、摘要及可用的预览图。
- 图片：显示缩略图、像素尺寸和来源应用。
- 文件：显示文件图标、文件名或文件数量；多文件作为一条记录。

当前项使用明显描边和状态变化。卡片宽度保持一致，超出屏幕的内容横向滚动。

### 5.3 操作

- 鼠标单击或 `Return` 执行当前默认粘贴行为。
- 左右方向键切换选中项。
- `Command + 1...9` 快速粘贴对应可见卡片。
- 右键菜单提供复制、纯文本粘贴、收藏到 Pinboard 和删除。
- 搜索输入期间键盘选择仍可使用。

## 6. 设置

### 6.1 通用

- 登录时启动。
- 音效。
- 默认行为：自动粘贴到原应用或只复制到剪贴板。
- 默认使用纯文本粘贴。
- 历史保留期限：1 天、1 周、1 个月、1 年或永久。
- 默认历史保留期限为 7 天。
- 清空历史。

### 6.2 隐私

- 屏幕共享时隐藏悬浮面板内容。
- 是否生成链接预览。
- 忽略敏感剪贴板内容。
- 忽略瞬时剪贴板内容。
- 自定义忽略应用列表。
- 退出应用时清空历史。

### 6.3 键盘快捷键

展示、录制和重置所有可配置快捷键，包括历史面板、前后移动、数字快速粘贴和纯文本模式。

首版设置中不出现智能、订阅、购买和 iCloud 同步页面或不可用入口。

## 7. 历史清理与缓存

应用启动后及后台定时执行过期记录清理。删除历史记录时同步删除其图片和缩略图文件；Pinboard 关系通过级联规则清除。删除 Pinboard 只删除收藏关系。

数据库或缩略图损坏不阻塞应用启动。无法解码的单条记录会被隔离或跳过；设置页提供清理预览缓存能力。网络链接预览失败时仍保存原始 URL，并使用无预览卡片样式。

## 8. 权限与首次运行

首次运行解释应用会读取剪贴板并在本机保存最多 7 天。只有用户开启或首次尝试自动粘贴时，才引导授予辅助功能权限。拒绝权限不会阻止历史采集、搜索和复制功能。

登录项使用 Apple 提供的 Service Management API。链接预览只访问用户复制的 URL，且可在隐私设置中关闭。

## 9. 验证策略

### 9.1 单元测试

- 四种内容类型解析和稳定指纹生成。
- 重复内容合并及排序。
- 隐私过滤规则和忽略应用匹配。
- 7 天默认保留策略及各期限清理。
- Pinboard 多对多关系及删除语义。
- 搜索和快捷键冲突校验。

### 9.2 集成测试

- 剪贴板监听、持久化和重新写回。
- 图片文件/缩略图生命周期。
- 源文件存在、移动或删除时的行为。
- 辅助功能权限缺失时的降级流程。
- 数据库迁移和损坏记录隔离。

### 9.3 手工验收

- Safari、Chrome、Finder、微信、WPS/Office 和 Xcode 中复制与粘贴。
- 单显示器与多显示器定位。
- 全屏应用、不同 Space、浅色/深色模式及缩放显示。
- 快捷键冲突、目标应用退出和应用重启恢复。
- 屏幕共享隐藏、暂停记录、忽略应用及退出清理。

## 10. 完成标准

首版完成时，应能在 macOS 15 或更高版本的 Apple Silicon Mac 上独立运行；持续记录并可靠展示四类内容；通过鼠标或键盘完成复制/自动粘贴；支持自定义 Pinboard、搜索、历史期限和隐私过滤；在权限缺失或内容失效时不会崩溃。
